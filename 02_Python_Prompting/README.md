## 📚 Python Prompt Engineering 실습

### Files
- HandsOn.ipynb : Python Prompt Engineering 실습 가이드

### 🎯 실습 목표
```
본 실습은 Python을 활용해 Watsonx LLM을 호출하고, Watsonx 내부 기능과 Langchain을 연계한 에이전트를 개발하는 실습입니다.
```

### 👥 실습 대상

watsonx.ai 플랫폼은 써봤지만 Python과 연계해 개발한 경험이 없는 분 <br>
Langchain 라이브러리를 통해 에이전트 개발이 어떻게 이뤄지는지 실습하고 싶은 분

### 🛠️ 주요 실습 내용

1. **IBM Watsonx SDK를 Python에서 사용**
    - watsonx의 파라미터 조정을 통한 응답 결과 확인
2. **Watsonx SDK와 langchain, OpenAI를 활용한 Prompt Engineering 실습**
    - Prompt Template 사용법 실습
3. **Langchain-ibm, ToolCalling을 활용한 에이전트 개발 실습**
    - Youtube 검색 AI : Langchain IBM + Langchain Youtube Search ToolCalling
    - 주식 및 뉴스 AI : LangChain IBM + yfinance + yfinancenews Custom ToolCalling
    - 통합 검색 및 세부 정보 검색 에이전트: LangChain IBM + DuckDuckGoSearch + Wikipedia ToolCalling
